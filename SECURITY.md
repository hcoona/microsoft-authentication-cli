# Security Policy

This is an unofficial, pre-release fork with no production-support or response-time
commitment.

Do not report a suspected vulnerability that contains sensitive details through a public
issue. Use this repository's private vulnerability reporting or a private draft security
advisory when available.

If the issue also affects the Microsoft-owned upstream project, follow the upstream
security policy and report it to Microsoft through the appropriate private channel.
Reporting it here does not report it to Microsoft.

Public issues may be used for non-sensitive hardening proposals, threat-model questions,
and already-disclosed dependency advisories.

Never include real tokens, authorization codes, cache files, account identifiers,
tenant-specific policy output, or private broker diagnostics in a report or test case.
